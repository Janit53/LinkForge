# LinkForge

LinkForge is a full-stack URL shortening platform that allows users to create short, shareable URLs from long links. It also supports bulk URL shortening through CSV files, custom short URLs, URL expiry, QR code generation, and user authentication.

## 🚀 Features

- 🔗 Create short URLs from long URLs
- 📦 Bulk URL shortening using CSV files
- 📄 Download generated short URLs as a CSV file
- ✏️ Create custom short URLs/slugs
- ⏳ Set an expiry date for short URLs
- 📱 Generate QR codes for shortened URLs
- 🔐 User authentication
- 📊 Manage created URLs
- ⚡ Fast URL redirection
- 🗄️ MongoDB database integration
- 📱 Responsive React frontend

Note: Many features are still to be integrated
